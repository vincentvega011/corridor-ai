## 14. Glossary
- **Taint / provenance**: a label on every value saying where it came from; untrusted values cannot move money without strong verification.
- **Quarantined reader**: a separate model that reads untrusted content, has no tools, and outputs only typed fields.
- **WYSIWYS**: What You See Is What You Sign; confirmation is bound to the exact displayed proposal.
- **Idempotency key**: unique key per action so it can execute at most once.
- **Hash-chained ledger**: each log entry includes the hash of the previous entry, so any edit is detectable.
- **Merkle root**: a single hash summarising many entries, used for inclusion proofs.
- **ASR**: attack success rate.
- **Baseline mode**: the naive agent used for comparison.
